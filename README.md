# fieldnote

Where your ideas take root.

Give a topic. Let the agent research it, draft it, and hand you back an output.

*Note: This is a training project for practicing full-stack development.*

## Stack

- **Backend**: Python, using [CrewAI](https://www.crewai.com/) with Gemini to generate blog posts
- **Frontend**: React / Next.js (planned)
- **Auth**: OAuth integration with Google and GitHub for users (planned)
